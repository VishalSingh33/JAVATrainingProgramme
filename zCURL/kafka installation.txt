Install Kafka At local windows:

1-Install wsl(ubuntu) and get update

2- download through ubuntu or if not possible the do it manually

https://kafka.apache.org/downloads from this : Source download: kafka-3.7.0-src.tgz (asc, sha512)

locate same at local : cd /mnt/c/Users/visha/Downloads
Use the ls command to confirm that the Kafka tarball is present in that directory: ls

You should see kafka-3.7.0-src.tgz listed.
// vishal33@DESKTOP-421LRF9:/mnt/c/Users/visha/Desktop/kafka-3.7.0-src$ = bash
Extract the Tarball: Once you're in the correct directory, extract the .tgz file:
bash : tar -xvzf kafka-3.7.0-src.tgz

After extraction, navigate into the Kafka directory (the name may vary based on the contents of the tarball):
bash: cd kafka-3.7.0-src

bash: ls -al
