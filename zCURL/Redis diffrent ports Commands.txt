if you start redis after few months and its failed to start then follw below:

The error [ERR] Node 127.0.0.1:6380 is not empty indicates that one or more of your Redis nodes already contain data or are part of a previous cluster setup.
Redis requires that nodes be empty before they can be added to a new cluster.

Here’s how to fix this issue:

1. Flush Data on Each Node
You can clear all keys from each node to make sure they're empty:

redis-cli -p 6379 FLUSHALL
redis-cli -p 6380 FLUSHALL
redis-cli -p 6381 FLUSHALL
redis-cli -p 6382 FLUSHALL
2. Reset the Cluster Configuration on Each Node
To remove any existing cluster configuration on each node, run:

redis-cli -p 6379 cluster reset
redis-cli -p 6380 cluster reset
redis-cli -p 6381 cluster reset
redis-cli -p 6382 cluster reset
Use cluster reset with caution, as this will remove any cluster configuration on the nodes.
If you're using redis-cli cluster reset in a production environment, ensure that this data and configuration can be safely cleared.

3. Retry Cluster Creation
Now, try creating the cluster again with the redis-cli --cluster create command:

redis-cli --cluster create 127.0.0.1:6379 127.0.0.1:6380 127.0.0.1:6381 127.0.0.1:6382 --cluster-replicas 0
This should proceed without errors if all nodes are empty and reset.

4. Verify the Cluster
After creating the cluster, verify its status with:

redis-cli -p 6379 cluster nodes
redis-cli -p 6379 cluster info
This should show all nodes as connected, and cluster_state:ok.
